Detailed Description

Middleware to implement READ/WRITE/ERASE from Persistant storage. This module implements the RM_MAP_PERSISTANT_W Interface.

Overview

RM_MAP_PERSISTANT_W module will implement the API's to READ/WRITE/ERASE to persistant storage using the MAP data structure.

Features

The RM_MAP_PERSISTANT_W module have the following key features:

  • Writing, reading, erasing user defined records of any length to data flash.
  • Reference data such as calibration data programmed at assembly or test time is preserved.
  • Reference data can be updated at run time.
  • Fault resilient design.

Usage Notes

  • Use the RM_MAP_PERSISTANT_W api's to read/write/erase from persistant storage.

Limitations

None.
