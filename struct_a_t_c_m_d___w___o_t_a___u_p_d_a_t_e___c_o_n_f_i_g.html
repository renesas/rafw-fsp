UINT ATCMD_W_OTA_UPDATE_CONFIG::is_resume

1 to resume a previously interrupted download (HTTP Range). 0 == normal full download. Always present so the struct layout matches across translation units; only honored when SUPPORT_OTA_RESUME is enabled.
